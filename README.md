﻿# CarAxia

Step 1:- copy the github repo url

Step 2:- open cmd terminal 

Step 3:- Git clone repo_url

Step 4:- Install XAMPP

    Download and install XAMPP on your system. Refer to XAMPP installation guide for details.

Step 5:- Start XAMPP Server

    Launch the XAMPP Control Panel and start the Apache and MySQL services.

Step 6:- Start SQL in XAMPP

    Ensure MySQL is running within the XAMPP Control Panel.

Step 7:- Open a Browser

    Launch any web browser on your system.

Step 8:- Access PhpMyAdmin

    In the browser's address bar, type localhost/phpmyadmin and press Enter.

Step 9:- Create Database

    In PhpMyAdmin, create a new database named testing.

Step 10:- Import SQL File

    Within the testing database, import the provided SQL file.

Step 11:- Place Project Folder

    Move your project folder into the XAMPP/htdocs directory to make it accessible.

Step 12:- Verify Installation

    Open your web browser and navigate to http://localhost/your-project-folder to ensure your project is running correctly. Replace your-project-folder with the actual name of         your project folder.
